# Hollow Knight Clone

A 2D action-adventure metroidvania game inspired by **Hollow Knight**, developed as a university project using **Java** and **LibGDX**.

## Overview

This project aims to recreate the core gameplay experience of a metroidvania game, including exploration, combat, enemy AI, platforming, and progression systems.

The project was developed for educational purposes to practice object-oriented design, event-driven programming, game development, and software engineering principles.

## Features

* Character movement and platforming
* Combat system
* Enemy AI and interactions
* Event-driven game architecture
* Menu and UI system
* Asset and resource management
* Fullscreen gameplay
* Custom animations and visual effects

## Technologies

* Java
* LibGDX
* Gradle
* Git
* GitHub

## Getting Started

### Prerequisites

* Java 17 or newer
* Git

### Clone the Repository

```bash
git clone http://github.com/mrsoltani/HollowKnight
cd HollowKnight
```

### Run the Project

#### Linux / macOS

```bash
./gradlew lwjgl3:run
```

#### Windows

```bash
gradlew.bat lwjgl3:run
```
