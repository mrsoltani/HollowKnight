Key facts confirmed from source (useful for future doc/feature work):
- 115 Java files in `core/src`, ~14.7k lines. Java 21, LibGDX 1.14.1, LWJGL3 3.4.1, Gradle + Construo.

- 8 charms, 3 notches. Sharp Shadow unlocked by pressure-plate puzzle; Void Heart by orb pickup.
- Saves: SQLite via `sqlite-jdbc` at `saves/savedata.db`, 4 slots, upsert + additive column migration.
- 13 Tiled maps; `TiledMapHelper` parses 12 object layers (logical, camera, teleport, danger, objectSpawn, laserSpawn, enemies, boss, door, charm, breakableWall, puzzle).
- Hazards: falling spikes, map lasers (IDLE/WINDUP/FIRING, one hit per cycle), breakable walls (3 hits).
- 5 achievements; speedrun target is 20 min in `AchievementManager` (strings.properties copy says 30 — inconsistency worth fixing).
- i18n: EN/FR via I18NBundle (`strings`, `dialogues`), runtime switchable.
- Cheats: Shift+F1..F6 (soul, heal, teleport, noclip, god, one-hit); `D` toggles hitbox debug.

### Damage-flash feature (COMPLETE — verified compiling)

Added a red hit-flash (~0.25s) to all enemy graphics per user request.

New file `core/src/main/java/com/Graphic/utils/DamageFlash.java`: shared static `draw()` helper.
Two-pass render: (1) multiplicative red tint (green/blue lerp 1.0→0.20 over the flash, so the
sprite never brightens), (2) additive red glow (src_alpha, ONE) fading with the timer, kept inside
the silhouette by texture alpha. Blend state restored afterward; passes negative w/h through unchanged
so flip-by-negative-size callers (FalseKnight) keep working.

Wired into:
- `BaseEnemy.java`: `protected float hitFlashTimer`; ticked in `update()` BEFORE the dying early-return
  (lethal hit still flashes on corpse); set in `takeDamage()`; `render()` routes the frame through
  `DamageFlash.draw`. Covers CrystalCrawler, HuskHornhead, Mosquito, CrystalGuardian.
- `CrystalGuardian.java`: its custom shoot-pose `render()` branch also uses `DamageFlash.draw` with the
  inherited `hitFlashTimer`.
- `FalseKnight.java`: own `hitFlashTimer`, ticked before stun early-return, set in `takeDamage()`,
  flip-aware `DamageFlash.draw` calls.

Verification: `./gradlew core:compileJava --offline -q` returns 0 (no errors). Scope note: Zote NPC and
CharmEntity are not enemies, so left untouched.

### README sound-design highlight (enriched)

User asked to "point to the art of the sound design" (different pitches of steps, etc.). Existing
"A world that sounds like a world" bullet was vague, so rewrote it grounded in real `AudioManager`
source facts:
- `playPitchedSFX(min,max)` jitters pitch per one-shot (walk 0.9–1.1, run 0.92–1.08, player slashes
  0.9–1.1, mosquito 0.96–1.04).
- Per-creature footstep bands reuse ONE foley clip ("enemy_ground_step" = Hero Walk Footsteps Stone):
  HuskHornhead 0.82–0.92 (low/heavy), CrystalGuardian/CrystalCrawler 1.05–1.16 (high/sharp).
- Boss (`subscribeToBossEvents`): random pick among 5 attack clips; distinct armour vs head hit banks
  split by phase (FALSE_KNIGHT_HIT vs FALSE_KNIGHT_HIT_PHASE2).
- Channels: footstep channel stops prev step (no pile-up); crystal_laser own channel.
- `playLayeredSFX` / `playRandomSFX` for variation-by-selection; master bus = masterV*volScale*pitch.
Kept the dramatic/short README voice. No compile needed (doc-only).
