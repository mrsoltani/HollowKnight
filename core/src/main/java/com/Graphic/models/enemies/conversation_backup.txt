  Plan: Enemy AI, State Machines & Test Screen

  Architecture (package com.Graphic.models.enemies)

  1. EnemyState enum — union of all states: WALK, IDLE, TURN, ATTACK_ANTICIPATE,
  ATTACK, ATTACK_LUNGE, SHOOT, EVADE, DEAD_AIR, DEAD_LAND.

  2. AnimationComponent (encapsulated, no God-class) — a small reusable helper
  each enemy owns. It loads a spritesheet strip via TextureRegion.split, builds
  one Animation<TextureRegion> per state, tracks stateTime, handles horizontal
  flipping, and disposes its own textures. This satisfies "encapsulate
  loading/animation/state-time inside each enemy" while staying DRY — the enemy
  declares which clips it has; the component does the mechanics.

  3. EnemyAI interface — update(delta, target, platforms), render(batch),
  renderDebug(shapes).

  4. BaseEnemy abstract class implements EnemyAI + your existing Damageable:
  - Fields: Rectangle bounds (hitbox), Vector2 velocity, EnemyState state,
  boolean facingRight, AnimationComponent anim, health, gravity constants.
  - Shared logic: gravity/ground collision against Array<Rectangle> platforms,
  wall-ahead & cliff-edge sensors (extracted from your ZoteNPC pattern), the
  universal death physics (takeDamage → if airborne DEAD_AIR, else DEAD_LAND; a
  falling DEAD_AIR that lands flips to DEAD_LAND), hitbox-vs-player damage
  dispatch, state-change helper, and default render/flip.
  - Abstract hooks: updateAI(...), getContactDamage(). Subclasses only write
  their brain.
  - getBounds()/takeDamage(...) implement Damageable.

  The four enemies (each its own file, frame data baked in from the reference)

  - CrystalCrawler — WALK constant velocity; wall/cliff sensor → TURN (plays
  2-frame turn, flips, resumes). 155×180.
  - Mosquito — rectangular visionBox (recomputed each frame to face its side);
  on player-in-box, latch target point → ATTACK_ANTICIPATE (pause) → ATTACK dash
  along a fixed vector (no re-aim) → ends on point-reached / wall / timer →
  IDLE. 220×155.
  - HuskHornhead — WALK (timed) ↔ IDLE (timed rest); forward vision box →
  ATTACK_ANTICIPATE → ATTACK_LUNGE high-speed straight charge until wall/cliff →
  back to IDLE. 239×219.
  - CrystalGuardian — stationary IDLE watching forward; player seen → SHOOT
  (wait out clip, no laser logic — just a // TODO laser marker + comment
  referencing enemies/Laser) → enrage WALK-charge at player → enrage timer ends
